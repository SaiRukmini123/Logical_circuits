Truth tables · Minterms · Maxterms · Expressions

Feed it a function.
Get back the whole circuit.

Enter a Boolean function any way you have it — a truth table, a list of minterms or maxterms, or a raw expression. This tool simplifies it, draws the gate-level circuit, and rebuilds it using only NAND gates and only NOR gates — then checks that all four agree on every input row.
